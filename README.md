# Fundamentals of C++ — CSE278

A collection of coursework, exercises, and programming practice completed for CSE278: Fundamentals of C++ at Miami University.

This repository contains my work with C++ and systems programming concepts, including object-oriented programming, memory management, file I/O, data structures, networking, web programming, and database interaction.

## Topics & Concepts

- C++ fundamentals and syntax
- Object-oriented programming
- Classes, inheritance, and polymorphism
- Header and implementation files
- File and stream I/O
- STL containers and algorithms
- Dynamic memory management
- String processing and parsing
- Networking with Boost.Asio
- CGI and HTML programming
- HTTP server development
- MySQL database interaction
- Command-line and systems programming

## Repository Structure

### Exercises

Smaller programming exercises covering individual C++ concepts and systems programming topics. 

- **Exercise 3–8** — C++ fundamentals, file processing, parsing, and object-oriented programming
- **Exercise 11** — Classes, STL containers, algorithms, and networking
- **Exercise 12–15** — Web programming, CGI, and database interaction
- **Exercise 17** — Pointer-based data processing and file input
- **Exercise 18** — Inheritance and polymorphism using geometric shapes
- **Exercise 22** — Web/database programming and query processing

### Homework

Larger assignments combining multiple programming concepts into complete programs.

- **Homework 2** — Dictionary and text-processing system
- **Homework 3** — Movie database and object-oriented programming
- **Homework 4** — C++ HTTP server implementation
- **Homework 5** — Movie database with MySQL integration and HTML output
- **Homework 6** — Movie database querying, parsing, and web-based interaction

### Practice

Additional C++ programming practice and experimentation. 

## Selected Work

### Object-Oriented Programming

Several assignments use classes, constructors, destructors, encapsulation, operator overloading, and inheritance to model data and program behavior.

### Networking & Server Development

The coursework includes networking using **Boost.Asio**, as well as the development of a basic HTTP server capable of processing client requests and serving files.

### Web & Database Programming

Later assignments combine C++ with HTML, CGI, and MySQL to create programs that process web requests, interact with databases, and generate dynamic HTML output.

### STL & Data Processing

The repository includes extensive use of C++ standard library features such as:

- `vector`
- `unordered_map`
- file streams
- string streams
- algorithms
- iterators
- smart pointers
